# Universal Theme 26.1 / Iris — verified runtime facts

Confidence: CONFIRMED unless marked. Evidence: Chrome DevTools MCP `evaluate_script` on app 102
page 500 + SQLcl `docker-demo` queries + APEXLang export, 2026-09-13.

## Identity
- `apex.env.APEX_VERSION = 26.1.4`, `APEX_BASE_VERSION = 26.1`.
- Theme 42 "Universal Theme", `baseTheme: ut-26.1` (`shared-components/themes/universal-theme/theme.apx`).
- Theme style **Iris** is current; the style is inherited from the base theme (no Iris style block
  is emitted in the app's `theme.apx`, only `currentThemeStyle: @/iris`).
- Other styles present on the instance (Vita, Vita Dark/Red/Slate, Redwood Light) are **out of
  scope** for this project.

## Markup hooks
- `<html class="page-<N> app-<ALIAS>">` — page/app scoping without extra classes.
- `<body class="t-PageBody t-PageBody--leftNav t-PageTemplate--standard apex-side-nav apex-icons-fontapex apex-theme-iris …">`
  `apex-theme-iris` is the theme-style hook; `js-navExpanded` / `js-navCollapsed--hidden` toggle with the side nav.
- Iris is light-only: `--ut-color-scheme: light`; `Iris.min.css` contains no `prefers-color-scheme` rule.
