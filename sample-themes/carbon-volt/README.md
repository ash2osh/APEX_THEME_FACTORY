# Carbon Volt

Dark technical theme for Universal Theme 42 / Iris: graphite surfaces, acid-lime directives, cyan telemetry,
square geometry, compact controls, and visible grid structure.

## Typography and provenance

- **Noto Kufi Arabic**, weights 400/500/600/700, is used for body and headings.
- Arabic and Latin glyphs are retained in every static WOFF2 face.
- Source: `google/fonts` commit `f2bd09badbc763d8757951d52deec29da27e85fb`,
  `ofl/notokufiarabic/NotoKufiArabic[wght].ttf`.
- License: SIL Open Font License 1.1 in `licenses/OFL.txt`.
- Runtime family: `ThemeFactory-carbon-volt-body`; Font APEX icons remain isolated.
