# Citrus Pop

Light playful theme for Universal Theme 42 / Iris: pale aqua canvas, deep teal structure, tangerine energy,
generous pills, buoyant cards, and friendly control proportions.

## Identity

Citrus Pop is the playful light system: pale aqua canvas, deep teal structure, pill navigation, buoyant cards,
soft fields, and tangerine actions with audited dark text. Its Tajawal faces and reduced-motion-safe lift keep the
playful density independent from Cobalt Press's editorial geometry.

## Typography and provenance

- **Tajawal**, its real upstream weights 400/500/700/800, is used for body and headings. Tajawal does not
  publish a 600 face, so the package does not relabel or duplicate another weight as semibold.
- Arabic and Latin glyphs are retained in every static WOFF2 face.
- Source: `google/fonts` commit `f2bd09badbc763d8757951d52deec29da27e85fb`, static faces under
  `ofl/tajawal/`.
- License: SIL Open Font License 1.1 in `licenses/OFL.txt`.
- Runtime family: `ThemeFactory-citrus-pop-body`; Font APEX icons remain isolated.
