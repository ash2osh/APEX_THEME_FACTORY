# sample-themes

One folder per theme package. Each holds the complete `css/` tree that `static-files/css` points at when
the theme is active, a README (direction, technique, declarative requirements), and `preview/` captures.

| Theme | Direction | Status |
|---|---|---|
| [linen](linen/) | quiet product — white chrome, hairlines, flat 8px surfaces, teal for actions only | active in app 102 (2026-09-13) |

Switch with `scripts/apply-theme.sh <name>`; the theme style stays **Iris** for every package.
